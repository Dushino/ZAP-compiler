# Code of Conduct

The ZAP! compiler is a hobby and educational project for the retro computing community. We want it to be a welcoming place for anyone interested in 6502 programming, Atari 8-bit development, compiler construction, or learning low-level programming.

## Our Standards

Everyone participating in this project — through issues, pull requests, discussions, or any other channel — agrees to:

- **Be respectful.** Treat other contributors with patience and courtesy. People come from different backgrounds and skill levels.
- **Focus on the work.** Critique code, designs, and ideas — not the people behind them.
- **Assume good faith.** Most disagreements come from misunderstandings, not malice. Ask before assuming.
- **Welcome newcomers.** Beginner questions are welcome. There are no stupid questions about 6502 programming or compilers.
- **Stay on topic.** Keep discussions related to the ZAP! compiler, the language, retro computing, and related technical topics.

## Unacceptable Behavior

The following will not be tolerated:

- Personal attacks, insults, or derogatory comments
- Discrimination or exclusion based on personal characteristics
- Sustained disruption of discussions or deliberate provocation
- Publishing others' private information without permission
- Spam, off-topic promotion, or commercial solicitation

## Enforcement

Project maintainers are responsible for clarifying these standards and will take appropriate action in response to any unacceptable behavior. Actions may include:

- A private warning
- Removing comments, commits, or other contributions
- Temporary or permanent ban from project spaces

## Reporting

If you witness or experience unacceptable behavior, please report it by:

- Opening a private security advisory on GitHub, or
- Contacting the maintainer directly via the email listed on the maintainer's GitHub profile

All reports will be handled with discretion.

## Scope

This Code of Conduct applies to all project spaces — the GitHub repository, issue tracker, pull requests, discussions, and any other channels associated with the ZAP! compiler project. It also applies when an individual is representing the project in public spaces.

---

*This is a simple, project-specific code of conduct. It is loosely inspired by community standards used in many open-source projects, adapted for the size and scope of this project.*
