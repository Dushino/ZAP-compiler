# Test 109: Comparison Operators in RPN

## Purpose
Tests comparison operators (==, <, >, >=) combined with addition in RPN expression.

## Calculation
- a = 10, b = 20, c = 10
- (a < b) = (10 < 20) = 1
- (a == c) = (10 == 10) = 1
- (b > c) = (20 > 10) = 1
- (a >= c) = (10 >= 10) = 1
- result = 1 + 1 + 1 + 1 = 0x04
