# Test 026: Nested Arrays

## Purpose
Tests 2D array indexing and element access.

## Memory Validation
- arr[2][3]: 2D byte array (2 rows, 3 columns)
- Initialized with values: [10,20,30,40,50,60]
- result @40000 ($9C40) = arr[1][2] = 60 (0x3C)

## Expected Output
Successful compilation and execution with result = 0x3C at address $9C40.
