Test: Missing Main Procedure
=============================

Purpose: Validates that compiler detects missing main() entry point

Error Type: Semantic Error - No main procedure defined

Expected Error:
- Compiler should report that no main() procedure exists
- Error should be clear that main is required
- Error should suggest creating proc main()

Code:
proc helper()
end

(No main procedure defined)

Expected Behavior:
- Compilation fails
- Error message mentions "main" or "entry point"
- Error is user-friendly
