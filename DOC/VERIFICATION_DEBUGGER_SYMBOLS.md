```python
def gen_file_header(self):
    self.emit("; Generated by Zap Compiler")
    cmd = self.command_line if self.command_line else "(command line not provided)"
    self.emit(f"; Command: {cmd}")
    if self.pruned_procs:
        removed = ", ".join(sorted(self.pruned_procs))
        self.emit(f"; Optimized out unused procedures (definitions and calls removed): {removed}")
    self.emit("; ==============================")
    self.emit("")
    self.emit(".DEBUGINFO +  ; Enable debug information for symbol names")
    self.emit("")
```

## How to Use (For Users)

### Build with Debug Symbols
```bash
make atari              # Linux/macOS
make.bat atari         # Windows
```

### Debug with VICE
```bash
x64sc -moncommands out/p1.lbl out/p1.prg
```

In monitor:
```
ll "out/p1.lbl"        # Load symbols
d ._main               # Disassemble main
break ._main           # Set breakpoint
```

## Build Pipeline Verification

```
ZAP Source
    ↓
codegen_expr.py emits .DEBUGINFO +
    ↓
ca65 -g (object file with debug info)
    ↓
ld65 -Ln (generates .lbl file)
    ↓
VICE/Oricutron loads .lbl
    ↓
✓ Symbol-based debugging enabled
```
